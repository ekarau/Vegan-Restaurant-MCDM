# Vegan-Restaurant-MCDM
You can run the website by typing python3 app.py in the terminal.

This web application evaluates vegan restaurants using the IF-AROMAN multi-criteria decision-making method.

As a user:
Click the "Start Evaluation" button from the homepage.
Enter your name or nickname.
Evaluate each criterion and restaurant alternative from your personal perspective (e.g. taste, service quality, price).

As an admin (ID: admin, Password: 1234):
View all evaluator submissions via "View All Results".
View individual evaluator data via "View Data", where each decision maker's personal inputs can be reviewed in detail.
Access all intermediate calculation results from the IF-AROMAN equations via "View All Intermediate Tables".
Add, edit, or remove criteria and alternatives from the admin panel.

All logic and fuzzy decision-making calculations are implemented within the Python code in this folder.
This application only uses the data collected from our vegan restaurant evaluation survey.
